Documentation

A circuit file is a list of parts and the nets that join their pins.

schem places every part, routes every wire, and checks the finished drawing against your file before you see it. These pages describe the file, every part type and its pin names, and how to change a circuit from the command line without reshuffling its drawing. Every example that is a whole circuit opens in the playground with one click.
