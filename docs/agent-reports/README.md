# Agent reports

This folder holds historical task reports and comparison images written by AI coding agents when completing branches in this repository.

- Each Markdown report (`<branch-name>.md`, plus older reports under [`codex/`](codex/)) records what a task changed, which commands ran, and any open questions, following the reporting rule in [`../../AGENTS.md`](../../AGENTS.md).
- [`img/`](img/) stores before-and-after or review PNGs referenced by those reports.
- The matching task briefs live in [`../agent-briefs/`](../agent-briefs/).

Reports describe the codebase at the date they were written and are not maintained as live documentation. For current user guides and reference docs, see [`../README.md`](../README.md) (`docs/README.md`) and [`../../README.md`](../../README.md).
