Project proposal

Schematics an AI agent can draw

Agents are good at knowing what connects to what. They are bad at deciding where each part goes on a page. This project lets the agent describe the circuit, and the engine places, wires and draws it at circuit-diagram.org quality, then shows the agent the result so it can fix it.

How it works

One engine, three doors in, a feedback loop out

The agent never handles x and y. It sends parts and connections, plus hints if it wants. The engine does the drawing work a human does by hand on circuit-diagram.org, then returns a picture and a list of problems. The agent looks, sends small edits, and repeats until the sheet is clean.

Where the gap is

Tools exist on both sides. None join them.

You are right that the existing code-based tools are not the answer, though the reason is more specific than looks. With schemdraw or CircuiTikZ the agent must decide every direction and position blind, so its drawings come out cramped or tangled, and it never sees the result. The missing piece is automatic layout with the agent in the loop.

Where it gets difficult

Stages 3 and 4 decide whether this succeeds

Drawing symbols nicely is a solved problem. Placing them the way an engineer would is not: power at the top, ground at the bottom, signal flowing left to right, feedback loops around op-amps, no wire crossing a label. The plan is to combine known schematic rules with a graph layout library (ELK, the one netlistsvg uses), let the agent add hints, and use the critic to catch what the rules miss. We should test this on real circuits early, before building the editor.
